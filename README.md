# Fusey

Генератор наклеек для электрических щитов. Шаблоны, свои надписи и иконки, точные размеры в миллиметрах, автоматическая раскладка на листы, линии реза и многостраничный векторный PDF. Работает в браузере, без сервера и регистрации.

Стек: HTML5, CSS3, Vanilla JS (ES-модули), SVG. Единственная библиотека: [jsPDF 2.5.2](https://github.com/parallax/jsPDF) (лежит локально в `js/vendor/`, CDN используется только как запасной вариант).

## Запуск

ES-модули и шрифты загружаются через `fetch`, поэтому нужен любой локальный HTTP-сервер (открытие `index.html` как файла не сработает):

```bash
python3 tools/serve.py 8080      # или: npm start
```

`tools/serve.py` отдаёт файлы с `Cache-Control: no-cache`, поэтому после изменений браузер всегда получает свежие JS и CSS. Обычный `python3 -m http.server` тоже работает, но браузер может держать старые модули в кэше (тогда помогает Ctrl+Shift+R).

Откройте <http://localhost:8080>. Сборка не нужна.

## Возможности

- **Формат DIN-рейки:** по умолчанию наклейка шириной в 1 модуль (17,5 × 50 мм), быстрый выбор 1–4 модулей, плюс горизонтальные размеры для дверцы щита и предупреждений.
- **Состав наклейки:** цветная иконка, заголовок (РОЗЕТКИ, СВЕТ), акцентная черта, несколько надписей (Коридор, Туалет, Ванная) и значок внизу (C16, 12V, номер группы). Белое поле между линией реза и рамкой, поэтому соседние наклейки не сливаются.
- **Библиотека шаблонов:** 70 шаблонов в 15 категориях, поиск, фильтр, добавление в один клик сразу нужным количеством копий, свои шаблоны.
- **Редактор наклейки:** заголовок, список надписей (Enter добавляет следующую), значок с быстрым выбором номинала, 4 шрифта (PT Sans, PT Sans Narrow, PT Serif, PT Mono), размер, начертание, выравнивание, интервал, отступы. Автоподбор: сначала уменьшается шрифт, затем слова переносятся по слогам с дефисом (КОНДИ-ЦИОНЕР, МОРО-ЗИЛЬ-НИК). Переполнение не скрывается: наклейка помечается на листе, в списке, в редакторе и в окне экспорта.
- **Иконки:** 57 двухцветных векторных иконок: 41 из открытого набора [Material Symbols](https://fonts.google.com/icons) (Rounded, Google, Apache 2.0) и 16 специфичных для щитка, нарисованных под тот же стиль (автомат, УЗО, реле напряжения, щит, евророзетка, заземление, мастер-выключатель, ввод, сплит-кондиционер, радиатор и др.). Цветной слой под тонким контуром, толщина линий «тонкие / обычные / жирные», переключатель «цветная / чёрно-белая», свой цвет акцента, положение слева, справа, сверху или без иконки, загрузка своей иконки из SVG.
- **Стили:** DIN-модуль, Minimal, Outline, Industrial, Bold, Warning, Text-only, Inverse, Custom. Цвета заголовка, надписей, акцента, фона, значка, рамки; толщина рамки, скругление, белое поле до линии реза.
- **Размеры:** произвольные ширина и высота для каждой наклейки, мм или см (переключение не меняет физический размер), модули и готовые размеры, групповое применение к выделенным.
- **Лист:** A4 (по умолчанию), A3, A5, Letter, Legal, свой размер; книжная и альбомная ориентация; поля; промежутки; раскладка «Для резки» (по умолчанию), «Плотно» или «По списку»; выравнивание в ряду; поворот на 90°; центрирование.
- **Линии реза для резки линейкой:** отдельный пунктирный слой поверх наклеек. Каждая граница ряда режется одним сквозным резом на всю ширину листа; у наклеек одной ширины вертикальные линии проходят сквозь все ряды (в том числе через промежутки между рядами) и выходят метками на поля листа. Совпадающие отрезки объединяются, двойных линий нет, и линия никогда не проходит через наклейку (проверяется тестом). Настраиваются цвет, толщина, сплошная или пунктир, длина штриха, отступ от края, продление до краёв.
- **PDF:** вектор (пути и текст со встроенными шрифтами, без растровых картинок), все страницы, точный размер страницы, кириллица извлекается как текст.
- **Проект:** автосохранение в `localStorage`, отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), новый проект, сброс с подтверждением, экспорт и импорт JSON с проверкой данных.
- **Перетаскивание на превью:** любую копию можно перетащить в любое место листа (мышью или долгим нажатием на телефоне): остальные наклейки расступаются на лету и показывают, как ляжет раскладка, после отпускания наклейка встаёт в свободную ячейку. Ручной порядок хранится в проекте, сбрасывается в настройках листа или перестановкой в списке наклеек.
- **Анимации:** наклейки плавно переезжают на новые места при изменении раскладки (FLIP), новые появляются с увеличением, листы перелистываются со сдвигом, карточки шаблонов и строки списка появляются по очереди, индикатор вкладок скользит, счётчики «подпрыгивают» при изменении. При системной настройке «уменьшить движение» остаются только плавные проявления без перемещений.
- **Без масштабирования страницы:** зум браузера отключён (meta viewport, щипок, двойной тап); Ctrl+колесо и Ctrl +/−/0 масштабируют только лист. Синяя подсветка нажатий и фокуса браузера убрана, фокус с клавиатуры виден в цвете приложения.
- **Интерфейс:** тёмная студия на desktop (шаблоны, наклейки и лист слева, холст в центре, редактор справа); на мобильных последовательные шаги «Шаблоны, Наклейки, Лист, Превью» с нижней навигацией и редактором в нижней панели. Режимы «Дизайн» и «Печать», масштаб (Ctrl+колесо, щипок, «Вписать», 100% = натуральная величина).

Горячие клавиши: `Ctrl+Z`, `Ctrl+Shift+Z`/`Ctrl+Y`, `Delete` удалить выбранные, `Ctrl+D` дублировать, `Ctrl+A` выбрать все, `Ctrl+P` экспорт, `PageUp`/`PageDown` листы, `Esc` снять выделение.

## Печать

Печатайте PDF в масштабе **100% / Actual Size** и отключите **Fit to page / Подогнать под страницу**. Итоговая точность зависит и от принтера, проверьте первую наклейку линейкой. Поля меньше 3 мм приложение помечает предупреждением: многие принтеры не печатают у края.

## Как обеспечивается точность

- Вся геометрия хранится в миллиметрах; размеры шрифта в пунктах (1 pt = 25,4/72 мм). Масштаб холста меняет только CSS-размер `<svg>`, у которого `viewBox` равен листу в миллиметрах.
- `js/sticker-layout.js` один раз вычисляет перенос строк, автоподбор шрифта и позиции иконки и текста. И SVG-превью, и PDF рисуют именно этот результат.
- Ширина текста считается по таблицам `hmtx`/`cmap` тех же TTF-файлов, которые встраиваются в PDF (это ровно те ширины, что jsPDF записывает в `/W`). В SVG кернинг и лигатуры отключены, чтобы экран совпадал с PDF.
- PDF создаётся с `unit: 'mm'` и явным `format: [ширина, высота]`. Ось Y у jsPDF направлена вниз, как в модели, поэтому координаты передаются без пересчёта; повёрнутые наклейки преобразуются по точкам.
- Иконки задаются SVG-путями, нормализуются в команды M/L/C/Z и выводятся в PDF настоящими кривыми.

### Раскладка

Детерминированная упаковка по рядам (shelf packing). Режим «Для резки»: копии группируются в полосы одинаковой высоты (в порядке появления в проекте), внутри полосы сортируются по ширине и заполняют ряды слева направо; у каждого ряда одна высота. Режим «Плотно»: First-Fit Decreasing Height, копии сортируются по высоте, ширине и порядку в проекте, каждая попадает в первый ряд (на любой странице), где хватает места. Режим «Как в списке»: Next-Fit без сортировки. Ряды дают прямые сквозные линии реза, одинаковые наклейки стоят рядом. Если наклейка больше рабочей области, она не размещается, показывается ошибка с обоими размерами, экспорт PDF блокируется. Реальные размеры никогда не уменьшаются автоматически.

## Тесты

```bash
npm test          # 22 модульных теста: единицы, пути, шрифты, перенос и слоги, состав DIN-наклейки, раскладка, сквозные линии реза, инвариант «линия не режет наклейку», проверка проекта
npm run test:pdf  # PDF через тот же код экспорта + проверка геометрии (нужен python3 с pdfplumber)
```

`tests/verify_pdf.py` проверяет число страниц и размер каждой страницы, положение, толщину, цвет и тип каждого отрезка линии реза (и отсутствие дублей), начало и базовую линию каждой строки текста с точностью 0,05 мм, размер шрифта, извлекаемость кириллицы и поворот текста у повёрнутых наклеек.

`tests/e2e-browser.js` выполняется в открытой вкладке приложения (например, через Chrome DevTools) и проходит интерфейс событиями DOM: пустой проект, создание и редактирование, шаблоны и поиск, иконки и стили, мм/см, форматы и ориентация, поля и промежутки, несколько страниц, слишком большая наклейка, отмена и повтор, групповое изменение, автосохранение, импорт и экспорт JSON, многостраничный PDF.

## Ограничения

- Переносы по слогам упрощённые (правила для русского языка без словаря), в редких словах место переноса может быть неидеальным.
- Шрифты ограничены четырьмя встроенными семействами с латиницей и кириллицей; символы вне шрифта (например, эмодзи или иероглифы) не печатаются, приложение об этом предупреждает. У PT Mono нет жирного начертания.
- У своих SVG-иконок не применяются атрибуты `transform`, градиенты и маски (при наличии трансформаций показывается предупреждение). Толщина линий своей иконки берётся из настройки наклейки.
- Линии реза прямоугольные; скругление углов влияет только на фон и рамку.
- Масштабирование страницы браузера отключено по требованию; для увеличения используйте масштаб листа.
- Раскладка рядами не является оптимальной упаковкой для сильно разных по высоте наклеек.
- Все данные хранятся только в этом браузере; для переноса используйте экспорт JSON.
